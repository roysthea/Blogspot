Cara menambahkan file README.md di GitHub dapat dilakukan langsung melalui website GitHub atau menggunakan terminal lokal (Git).
Menambahkan README Lewat Website GitHub
Masuk ke akun GitHub Anda.
Buka repositori yang ingin diberi file README.
Klik tombol Add file di sebelah kanan atas daftar file, lalu pilih Create new file.
Ketik README.md pada kolom nama file di bagian atas.
Tulis isi atau deskripsi proyek Anda menggunakan format Markdown pada editor yang tersedia.
Klik tombol Commit changes... di pojok kanan atas untuk menyimpan file ke repositori.

Menambahkan README Lewat Terminal Komputer (Lokal)
Buka aplikasi terminal atau command prompt di komputer Anda dan arahkan ke folder proyek.
Buat file baru dengan perintah touch README.md (atau buat manual lewat text editor).
Masukkan perintah untuk mencatat perubahan (staging dan commit):
bash
git add README.md
git commit -m "menambahkan file readme"
Gunakan kode dengan hati-hati.
Kirim file ke GitHub menggunakan perintah: 
bash
git push origin main
Gunakan kode dengan hati-hati.
